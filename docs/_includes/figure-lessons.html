建卡与管理素材

  1. 在「AI助手 → AI作图」点「新建作图卡片」，填写卡片名并选一种模式；回到项目列表可用「项目类型」筛卡片。卡片记录排版、对应素材及修改历史。

右侧预览和 AI 修改按钮

软件原图／AI 作图
在两种预览之间切换。左侧设置改变软件原图；想用新设置继续做 AI 图，先生成并切到新的软件原图。若要延续上一次版本，切到「AI 作图」。
缩小／放大／适合窗口／抓手
滚轮也能缩放。「适合窗口」恢复完整画面；开启抓手后拖动平移。想框选给 AI 的区域，先关闭抓手再拖。
绘图脚本模型、AI 对话记录、修改要求
从已开启的模型中选择。记录框显示以往请求和说明；下方输入本次改法。示例：「把选中图例上移 3 pt，保留数据和统计」；需要全图调整时可不框选。
向模型提供原始预览及项目素材

AI作图／继续修改、取消任务

撤销最近一步，首次修改也可撤回；重做恢复刚撤回的版本。应用后重新核对轴、数据点和统计。删除卡片会清理对应缓存。
检验结果、导出
qPCR 和 Excel / CSV 在生成检验结果后可查看比较对象、样本量和 P 值。「导出」针对当前显示版本，按可用工件提供可编辑 PDF／SVG、数据 CSV、检验结果或排除记录；校对预览后再选格式。

28WB / gel：截条带、排泳道、算相对灰度

逐条建图：从条带原始图到排版

  1. 建「WB / gel 作图」卡。按膜或曝光添加原始图；同一个文件可反复选不同区域。点击素材行，按「从所选素材添加条带」。
  2. 打开选区后拖出目标条带；拖框内移动、拖控制点改变大小、Shift＋拖动重选，方向键微调。若原始图确有倾斜，可先点「标尺校平」，沿基准画线，再重查选区；「复原角度」撤回旋转。
  3. 填蛋白／核酸名和左到右泳道标签，确认选区。回到项目可双击编辑、拖动或「上移／下移」排序。「移除选区」只移除选区。加齐后点「本地预览」。
  4. 同名目标合为同一行；第一组重复目标的泳道组合决定列序，后来各行按标签归列，缺失位置留空。排版后核对标签与物理泳道是否一致，必要时改标签或在 AI 预览中提出对齐要求。
自由长宽／固定宽高比／固定像素
自由任意框选；固定比例用「宽／高」控制形状；固定像素用它们控制裁剪尺寸。支持正小数。「X／Y」定位左上角，「宽 px／高 px」显示选区尺寸。
蛋白／核酸、泳道标签、分子量／片段长度
目标名决定条带归行；泳道标签以逗号分隔，可有重名，会按物理位置区分。后续选区可沿用首组标签，应逐一校对。分子量或片段长度可留空，填写时带上实际单位。
指定泳道、AI 建议选区、确认选区／取消
可写「截取第 2–5 个泳道的某条带」请 AI 建议框的位置。模型建议后仍应核对；「确认选区」才加入项目，「取消」不保存此次编辑。
{% include guide-shot.html id='figures-images' %}

排版例：蛋白 A 若先添加一条 input、再添加一条处理样本，先固定这一行的左右顺序。蛋白 B 即使先加入处理样本、后加入 input，只要泳道标签正确，仍会按 A 的列序对齐。

相对灰度：对照、自动阈值与手绘

  1. 如需定量，先确保各待分析条带有同样的泳道顺序，首条至少填写两个标签，再打开「相对灰度」，勾选「计算并展示条带相对灰度」。
  2. 按图像背景选择「条带类型」，在「蛋白／核酸」切换目标，「对照泳道」逐条设置；未修改时沿用首条。以泳道序号区分重复名称。
  3. 「自动阈值选区」先检查各泳道是否正确圈出；找不到条带的小矩形代表零信号，应回看图像。有需要切换「手绘目标区域」后用「圈选泳道」选择目标，可修正重叠选区。「清除当前泳道框」只清除所选框；重新圈选后再确认。
  4. 「展示方式」可在泳道下方显示数值，或在图右侧显示柱状图与圈选示意。确认后本地重新绘制，再核对标注、对照与裁剪，最后导出图件。

29IF：按处理组组织通道并同步裁剪

从原图、共用选区到多通道出图

  1. 建「IF 作图」卡，按处理组添加各通道素材。组内通道必须已配准且像素尺寸一致。先把每组的文件按同一通道顺序排列，方便后续自动带入编号。
  2. 选本组一张参考图，点「从所选素材添加处理组」。在「处理组名称」填组名；在「通道名称=素材编号」每行输入一条，例如 DAPI=1、目标通道=2。编号来自左侧列表，同一组须包括参考图，名称和素材都不要重复。
  3. 按自由长宽、固定宽高比或固定正方形像素选区；X/Y 与宽高精确定位。比例尺按采集标定设置，勿按截图显示缩放倍数估算。逐组确认，后续组默认沿用第一组通道顺序及对应编号，可单独更正。
  4. 在项目列表双击编辑处理组，或拖动、「上移／下移」调整顺序；「移除选区」只删除该处理组裁剪。某组修改尺寸时留意是否把尺寸应用到同项目其它组。生成本地预览，逐列检查同一视野、标签、通道顺序和比例尺后再导出。
通道名称=素材编号
一行对应一张素材图，行顺序就是通道顺序。新增后续处理组时先对照原始文件名确认自动匹配，避免把 DAPI 与目标通道调换。
在哪些图片添加比例尺、图像标定、比例尺长度
选择不添加、本组全部图片或指定通道。标定填 pixel/μm，比例尺填 μm；两者相乘是线段在源图上的像素长度，必须小于选区宽度。
缩放、平移与确认选区
「适合窗口」便于找视野；放大后用抓手移动画面，关掉抓手后再改框。确认后同一个矩形应用到本组所有通道。
{% include guide-shot.html id='if-channels' %}

通道例：示例中第 1、2 张属于对照组，第 3、4 张属于处理组；若首组用 DAPI=1、目标通道=2，后续组通常是 DAPI=3、目标通道=4。若素材实际排列不同，请以原始通道为准修正编号。

30qPCR：从 Ct、独立重复到表达与富集图

导入仪器表格并设置分析方式

  1. 建「qPCR 作图」卡，添加仪器导出的 Excel／CSV。工作表留空读取默认表；若有多张表，填写工作表名称。软件自动定位表头。
  2. 确认样本、目标基因、原始 Ct 对应列。可用表头或 #列号；Ct Mean 可选，缺失时从原始 Ct 算均值。只有至少三个技术复孔时才按 0.5 阈值检查端点，两个复孔不按此阈值剔除。
  3. 「分析方式」选 RNA 相对表达或 ChIP-qPCR／RIP-qPCR 富集。RNA 模式填映射后的内参基因与对照组，使用相对表达结果；富集模式按组选择 Input 或 IgG，不沿用 RNA 的内参设定。
{% include guide-shot.html id='figures-data' %}

重复、IP 配对与样本／基因映射

设置重复组
默认每文件一个独立重复。文件含多套生物学重复时，打开相应素材页或数据块，点「新建重复篮子」后拖拽样本格，或多选后用「移动选中样本…」；「剩余样本归为一组」可一次分配余项。不用的样本留待分配；「删除篮子」退回格子。「设置处理名称…」统一条件名，勾选「使用此数据块」才能纳入。
IP 对照类型、设置 IP 配对
只用于富集模式。选择 Input（2Ct(Input)−Ct(IP)）或 IgG（2Ct(IgG)−Ct(IP)）。在同一重复内把对照放在配对上方、IP 放下方，也可用选项与「绑定配对」。错误配对用「取消配对」修正。后续同名样本可沿用首组配对，仍需核对。
设置样本与基因映射
在各素材或重复对应页统一样本、基因名称。首个素材的同名映射可用于后续页，可逐页改写。选中起始单元格可粘贴 Excel／CSV 的多行；单行多列可转成纵向值，覆盖前先核对起始行与行序。
设置样本分组与归一化
分别设分组名称、处理条件、归一化参考样本。可互换两类标签，从下拉复用已有值，或多选格批量填。参考样本可用「应用到所选行」批量选择，也可选不归一化。改过设置后比较组对会恢复「不进行统计检验」。
{% include guide-shot.html id='qpcr-repeat' %}

重复组例：同一张表包含 Control1、Treated1、Control2、Treated2 时，若数字表示同一次独立实验，将 1 的两种处理放同一篮，2 的两种处理放另一篮。不要按 Control 和 Treated 分篮；那样会拆散原本可以配对的重复。

画图、选择检验数据及核对结果

图标题、X 轴、Y 轴
设置读者实际看到的文本。RNA 默认 Y 轴为 Relative RNA level；富集数据应在标签中说明除以 Input 还是 IgG，以及是否做过额外归一化。
检验数值与比较组对
RNA 模式可选作图值或 ΔCt；富集模式核对界面所示的富集倍数或对应 Ct 差。先确定检验尺度，再选方法。默认不比较；需要比较时选「任意两两组」或「手动选择组对 → 选择组对」。配对检验按同一独立重复匹配，不能用技术复孔当作独立配对。
图类型、误差线、重复点、配色设置
要比较同一基因的处理条件，可选分组并列柱图或分组柱形图＋重复点；有顺序的时间点可选折线。默认误差线为均值 ± SD，也可用 SEM 或不显示。「以圆点展示独立重复」用于检查汇总值对应的重复分布。配色参见下一节。

点「本地预览」，确认重复数、参考组、误差线含义和检验尺度。生成统计后打开「检验结果」查看，再从当前预览导出图件、作图数据或统计 CSV。若提示没有可用 Ct，按顺序核对工作表、列名、有无可用数值、重复篮、IP 匹配和映射名称。

31Excel / CSV：识别矩阵、分组统计与重绘

输入矩阵并识别 Column 或 Grouped

  1. 建「Excel / CSV 作图」卡，导入数值表。若工作簿有多张表，可填工作表名。程序读取该表左上角第一个可用数值矩阵；想画另一个区块，请整理成独立工作表。
  2. 在「表格结构」选择每列一组或每行一组，观察「识别结果」。Column 适合每组一列（或一行）重复值；Grouped 适合有两层分类、每条件下有重复位置的矩阵。数字文本可转为数值；缺行列名时会生成 row1、col1 等。
  3. 先核对组数、组名、重复方向，再设标题与轴标签。若图上组次序或重复对不上，先回到表结构确认，而非直接改标签。按百分数显示时，1 会显示为 100%，不要预先把比例又乘 100。
{% include guide-shot.html id='figures-table' %}

配对例：若 Control 与 Treated 两列的第 1 行来自同一个对象，第 2 行来自另一个对象，选「每列一组」，保留同行对应。若对象并非一一对应，即使表格整齐也不应选择配对检验。

分组、归一化与比较

Column：设置样本分组与归一化
用「分组名称」管理主类别，「处理条件」区分子类别；已填的值可下拉复用。选多个格点「填写所选格子」，或用「互换分组名称与处理条件」。选多行指定同一个归一化参考或不归一化，点「应用到所选行」。
Grouped：设置归一化
保留已识别的分组结构，选择某个对照组，以该组均值归一化；不需要归一化时选不归一化。改分组或归一化后，重设比较组对。
统计检验、比较组对、选择组对
非配对可选等方差 t、Welch 或 Mann–Whitney；配对有配对 t 或 Wilcoxon 符号秩；多组整体检验可用单因素 ANOVA 或 Kruskal–Wallis（均为独立样本）。方法应按分析设计选。手动模式才用「选择组对」；只画图时保留不检验。
配对规则
Column 每列一组时按同行配对，每行一组时按同列配对。Grouped 按组中相同重复位置配对。缺测时不要把后面的值挪去填空位，应保留位置并核对检验窗口实际纳入的配对数。

图类型、配色、导出及排除点

图类型
柱图用于看汇总；散点显示每个观测值，上层黑短线表示均值；箱线、小提琴、频数和累积分布用于看分布；分类折线用于有顺序的类别；浮动柱标最小到最大。Grouped 可用并列、按条件排列、堆叠、带重复点、对齐散点和分组折线等布局，菜单按识别结构变化。
误差线与配色设置
可选均值 ± SEM、均值 ± SD 或不显示；按图类型核对实际绘制。色板可用 Nature／NPG、Matplotlib 渐变与取色数量，或输入自定义十六进制颜色并通过「选色／屏幕取色」调整。颜色数量不足时从头循环。
框选排除与导出
生成软件原图后框选需要排除的观测点，在 AI 修改里明确要求排除并重算。对照原图与新图的均值、样本量及检验结果；在结果可用时导出排除记录。源工作表不变，也不要把仅隐藏图形当成排除数据。
