22从文章总结到增量 AI 报告

阅读单篇文章并核对来源

  1. 打开文章详情，选择「AI总结文章」。如果有本地原文，先在收藏中关联 PDF。没有 PDF 时可打开已有权限的 DOI 网页，在内置浏览器等待识别或点击「读取当前文章」。正文无法读取时，可改选本地 PDF。
  2. 在总结窗口确认分析模型和材料覆盖范围。只读到标题或摘要时，不要把总结当成已经核对全文；若网页需要登录、授权或人机验证，由用户自行完成。使用预印本时同时核对正式发表记录及版本。
  3. 按需切换中文简报、英文简报或新闻稿。阅读主要发现和证据来源，再保存结果供离线阅读，或导出简报／新闻稿 PDF。模型图可单独保存，图形未生成时也可以先保留文字。

关键词推荐与批次报告

  1. 不确定如何检索时，从关键词方案首页打开「AI推荐关键词组」，描述研究对象和问题，从历史或结果中复制有用的英文词。按第 3 节拆到 PubMed 和预印本两个输入框。
  2. 刷新关键词方案后，从方案卡打开「AI报告」，检查批次新增篇数及时间范围。点击生成按钮后，逐篇读取结果；没有新增文章时，不会为了生成空报告调用模型。
  3. 多个 AI 任务可分别保存或取消。取消会停止本地等待和后续调用，已经提交到云端的请求仍可能计费。换模型继续时，先检查将要复用的历史材料。

23领域知识库：建立并补充证据

  1. 在「AI助手」点击「AI模型训练」卡，再点「新建知识库」。写一个能区分用途的名字，例如「DNA 复制与复制压力」。
  2. 选择分析模型和收藏文章；要提高证据覆盖优先关联可用 PDF。点击「读取新文献并更新领域知识库」，逐项检查已读篇数和实际覆盖范围，再保存。
  3. 以后从同一张知识库卡打开，添加新文章继续补充。已整理过的证据可以复用；知识库整理文献记录和证据笔记，不修改模型权重。
  4. 在「AI提出科学问题」或「AI reviewer」的领域知识库下拉框选择它。若由不同模型继续整理，软件会询问是否把已有证据笔记交给当前模型。

24AI 提出科学问题：从限制出发做选题

  1. 打开「AI助手 → AI提出科学问题」，写清研究领域和目前卡住的问题。也可从「历史记录」打开之前的主题继续。
  2. 可从领域知识库加载已整理的证据，或注明希望讨论的范围。在问题里区分已知现象、证据空白和希望模型比较的解释。
  3. 阅读结果时，优先核对引用能否支持该判断，区分已有结论和待验证假说。继续追问时，可要求列出替代解释、限制和可证伪条件。需要留档时保存历史或按界面选项导出。

25AI reviewer：阅读和追问模拟同行评审

  1. 打开「AI助手 → AI reviewer」。在输入页添加待审稿件（PDF、DOCX 或图片），补充研究范围。需要逐页解读 PDF 图表时选择支持视觉输入的模型；可按需加载相关领域知识库。
  2. 点击 Read manuscript and review，在 Peer Review 页依次阅读 Summary and significance assessment、Major comments 和 Minor comments。对关键意见回看原稿页码、图表和引用依据。
  3. 可继续追问某条意见、保存历史或导出 PDF。它是模拟评审，不代表期刊正式审稿结果。历史记录引用原稿路径，移动文件后需要重新选中源稿再续审。

26AI 寻找文章：用证据卡核查文献

  1. 打开「AI助手 → AI寻找文章」，点「添加对话卡片」。把目标写具体，例如「比较 R-loop 检测方法的综述，请说明各方法的适用范围与局限」。
  2. 可点「科研资料」添加背景文档，说明所需文章类型、时间段或不应纳入的材料。按 Enter 发送，Shift+Enter 换行。按分子或组合检索时，检查不同分组是否反复引用同一篇文章。
  3. 回答内点击引用编号跳到对应文献卡。核对题名、DOI、出处和材料覆盖后再收藏；关注「全文」还是「摘要」支持该结论。后续可继续对话、修改提问，或将确认过的文章加入相应收藏组。

生成后：左侧回答、右侧证据卡片

引用编号与分栏
点击左侧回答的 [1]、[2] 等编号，右侧独立滚动到对应卡片；在卡片较多时可单独滚动右栏。拖动中间分隔条可分配左右栏宽度，拖动回复的侧边还可调整整条回复宽度。
文章详情／收藏
先点「文章详情」核验题名、来源、DOI 和读取范围，再点「收藏」并选择分组。状态已显示「已收藏」时不用重复添加。
科研资料／停止／复制、编辑、删除消息
「科研资料」添加你选定的文件，也可拖放；提交前用「清除附件」移除不需要的材料。「停止」取消本地等待。消息可复制，自己的问题可编辑并重新发送；删除会移除对应消息独有的缓存，已收藏文章保留。

32AI Protocol：提取、编辑和分享

  1. 打开「AI助手 → AI Protocol」并新建卡片。添加本地论文、学位论文、收藏文献或自拟方法；添加图片时选支持图片输入的模型。
  2. 明确写清需要提取的内容，例如「只整理本文中的 Western blot 步骤，并标记原文没有说明的条件」。选择分析模型，按需使用配置好的绘图通道生成流程图。
  3. 生成后对照原文核对步骤、单位、数值和材料出处。未核实的文献不会进入推荐：找不到某条条件时应标注缺项。点击编辑入口修改草案，确认后保存。
  4. 用 Word 或 PDF 导出便于校对；需要把可继续编辑的方案转给同事时，在卡片列表打包分享，对方使用导入。检查导出的格式和材料是否符合分享范围。

33清理资料与反馈问题

备份后再清理

在「设置 → 本地数据」先备份资料库，再选「清除无用缓存」。它清理已经删除的方案、作图卡片和对话留下的缓存。需要换盘或换电脑时使用数据目录的迁移功能；完成后先确认收藏和关联 PDF 能打开。

{% include guide-shot.html id='cleanup-data' %}

选择私密反馈或公开问题

  1. 在左侧点「反馈」。不希望公开的问题选择「反馈发送到开发者邮箱」；适合公开讨论的建议可选择 GitHub Issue。
  2. 填写系统、版本、复现步骤、预期与实际结果，并按需附错误文字。私密表单勾选同意后发送；公开渠道仅打开预填页面，由你在 GitHub 上再次检查并确认提交。
  3. 不要填写 API Key、学生访问 ID、患者信息或未公开资料。如果私密反馈暂不可用，保留草稿并稍后重试。
