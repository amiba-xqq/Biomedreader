21配置 AI、本机 Codex 与课题组

个人通道与本机 Codex

  1. 进入「AI 部署」，选择所需文字服务，配置个人 API Key 并检测连接。DeepSeek、OpenAI API、Kimi、GLM 等以软件列出的服务和模型为准。
  2. 可以为同一模型选择优先「个人 API Key 直连」或「课题组授权」；优先通道不可用时才尝试已配置的另一条通道。余额或用量只在服务支持且额度可查时显示。
  3. 使用本机 Codex 时选择「ChatGPT Codex · 本机连接」，按提示登录自己的账号，点击「检测 / 刷新模型」，再到设置中选择模型和可用推理强度。它独立于个人 API Key 和课题组授权，模型列表以该机器与账号的实际检测结果为准。

PI 管理与学生访问

PI 登录课题组管理后，可配置多个服务商、创建或停用学生访问 ID，查看按日用量、近一年日历及按平台筛选的消费。学生使用 PI 分发的 ID 登录；同一 ID 最多同时绑定两台设备。退出需要联网确认并释放本机占用，网络失败时请稍后重试。PI 停用后，设备名额不会恢复使用权限。

模型图走独立通道

在模型图设置中选择阿里云百炼、火山引擎方舟、GLM-Image、分析模型自带工具或跳过。文章总结优先沿用可用的论文原图；仅在需要时请求生成图。遇到超时、限流或模型权限错误，先检查绘图通道、模型 ID、端点、密钥所属项目和可用额度。绘图失败时仍可保留文字结果。

22从文章总结到增量 AI 报告

  1. 从文章详情打开「AI 总结文章」，选择分析模型。优先使用已关联 PDF 或可访问正文；只有摘要时检查结果注明的材料范围。
  2. 按用途切换中文或英文简报、新闻稿。保存后可离线查看；需要分享时导出摘要或新闻稿 PDF，模型图可单独保存。
  3. 关键词不明确时用「AI 关键词推荐」生成英文检索建议，可逐项复制并查看历史。需要定期追踪同一主题时，基于关键词方案运行增量 AI 报告；没有新增时不调用分析模型。

从 DOI 网页或本地 PDF 读取正文

如果没有已关联的 PDF，可以尝试通过本机打开已有权限的 DOI 网页。在内置浏览器中等待正文可读，或使用「读取当前文章」手动继续。遇到登录、授权或人机验证时请自行完成；若浏览器无法读取，可选用本地 PDF。对预印本，请核对正在阅读的版本与正式发表记录。

保存模型图时优先使用可用的原始图表文件；如果服务只提供位图，文件格式取决于实际返回。请核对图中结论是否来自原文。

多个 AI 任务可分别运行、保存或取消。取消会终止本地等待与后续步骤，已提交的云端请求可能仍计费。换模型继续对话时，在确认前检查将发送的历史材料。

23科研对话、知识库、科学问题与审稿

  • AI 寻找文章：描述研究问题，可加入材料和约束条件，打开正文引用编号定位右侧文献卡，核实后收藏到指定分组。正文与证据卡分栏滚动，历史消息可复制、编辑或删除。
  • 领域知识库：把核实过的论文保存为可复用的证据库，供科研对话、科学问题和 AI reviewer 选用。它整理资料，模型权重不变。
  • AI 提出科学问题：选择材料后，从证据缺口、理论冲突和技术限制出发，检查哪些是已有结论，哪些只是待验证假说。
  • AI reviewer：选择稿件与可选证据，按 Summary and significance assessment、Major comments 和 Minor comments 阅读英文意见，并按需保存历史或导出 PDF。
  • 内置科研技能：系统根据任务加载科研写作、批判性评估、头脑风暴、假说生成、同行评审、文献检索与文献综述等技能。由研究者核对结果和引文。

可选：Biomni 与分子主题检索

需要 Biomni 时，在对应卡片配置 Biomedical AI Agent 的个人 API Key，通过「验证 Key／刷新档位」检查账户可用档位。确认材料和服务费用再提交任务。在文献助手中按分子或组合整理检索时，检查分组证据及跨组重复文献。

24AI 作图：先出软件原图，再连续修改

  1. 从「AI 助手 → AI 作图」建立 WB / gel、IF、qPCR 或 Excel / CSV 卡片。添加素材，完成左侧设置并生成「软件原图」。
  2. 切到合适的预览，框选要修改的区域并描述目标。例如「保持数据不变，把选中两行上移并缩小行距」「让选中的色条成为连续渐变」「把边线改为 2 pt，底边不加线」「添加竖线和竖排文字」。
  3. 要接着上一步改图，请切到「AI 作图」版本。软件复用本卡片最近成功的绘图脚本与对话；是否向模型提供预览和素材由该窗口的勾选项决定。删除卡片会清理对应本地缓存；也可从设置清理无用缓存。
  4. 更改左侧设置会更新「软件原图」，已有「AI 作图」结果仍保留。若要基于新设置继续，请先切回新的软件原图。可撤销首次或最近一次 AI 修改，并重做一次。
  5. 核对图例、坐标、单位及统计后导出可编辑 PDF / SVG。Excel / CSV 可针对当前预览框选观测值并重新计算图中的统计，原始文件不改写；需在分析记录中明确标注排除依据。

25WB / gel 与 IF：选区、通道和泳道

  • WB / gel：从素材添加条带，选区宽高可填正小数。录入泳道标签并核对选区，可做标尺校平。新增后续截图会沿用首组泳道设置，仍可手动调整。同名泳道在相对灰度中按物理位置区分。
  • 同一目标的多条带：同名蛋白或核酸各占一行，行顺序按首次出现；列顺序取第一个重复目标的泳道组合。后续条带按泳道归列，即使素材顺序相反也会对齐。缺失的条带位置留空。
  • 相对灰度：可为不同蛋白或核酸选不同对照泳道，未改动时沿用第一项的对照设置。手绘区域可有重叠；自动阈值找不到区域时，用泳道中央小框标示并记为 0。请人工核对无信号与漏圈的区别。
  • IF：选取原图区域后为通道设置标签、素材编号与同步裁剪。后续系列默认采用第一组的通道顺序和对应素材映射，也可逐组调整；选区宽高支持正小数。

26qPCR 与 Excel / CSV：分组、归一化与统计

qPCR 导入与重复组

  1. 添加仪器导出的表格，软件自动定位表头，Ct Mean 可留空。可从原始 Ct 计算均值；少于 3 个技术复孔不按 0.5 阈值剔除。有生物学重复时，每份文件默认是一个重复组。
  2. 同一个文件含多个独立重复时，只添加一次，先打开「设置重复组」，把样本拖动或多选移入不同重复篮，可留出不参与分析的样本。删除篮子会把样本返还至待分配区。对配对检验，检查样本确实属于同一独立重复。
  3. 需要做 ChIP-qPCR / RIP-qPCR 时切换富集模式。在各重复内用「设置 IP 配对」将 IP 与对应 Input / IgG 手动绑定。后续素材样本完全相同可复用首组配对。RNA 相对表达模式则配置内参和对照。
  4. 最后设置样本与基因映射，再设置组名、处理条件、参考样本或不归一化。组名和处理条件可交换，能下拉复用，也可选中多格批量填值。后续素材会复用首组同名映射，也能单独编辑；映射名称支持复制粘贴多行，来自横排的一行多列可转成纵向。

qPCR 的 RNA 模式默认 Y 轴为 Relative RNA level，误差线默认均值 ± SD。富集模式可将同一基因的条件放在同一簇中，也支持分组归一化及按重复显示点。

Excel / CSV 数值矩阵

  1. 选择「每列一组」或「每行一组」。软件读取所选工作表左上角第一个数值矩阵，识别 Column 与 Grouped；可识别以文本保存的数字，缺少标签时用 row1、col1 等代替。
  2. Column 可配置样本分组，Grouped 按选定对照组的均值归一化。可批量为多个样本设置参考样本或不归一化，选择普通数值或百分比显示。散点图用黑色均值短线展示组均值。
  3. 比较组对默认「不进行统计检验」，调整分组或归一化后恢复此默认。要做检验请重新选择比较组对：Column 按同一行或同一列配对，Grouped 按组内对应重复位置配对。请核对缺失值与正确的配对方向。

27AI Protocol：提取、编辑与分享

  1. 打开「AI 助手 → AI Protocol」，添加论文、收藏文献、学位论文或自拟方法，也可添加图片并选择支持图片输入的模型。
  2. 用一句话写明要提取的项目，如「总结这份资料里的 Western blot 方法，列出材料和步骤」。选择分析模型（可用本机 Codex），按需勾选用绘图通道生成流程图。
  3. 生成后查看中文方案，核对原始材料、引用和缺项，补充人工审核内容。检索到的补充材料由 PubMed 核实，未核实的引用不加入推荐。
  4. 在编辑器保存和整理，可导出 Word 或 PDF，或批量打包分享和导入。导出前检查数值、条件和引用确实来自可靠材料。

28清理资料与反馈问题

在设置中使用「清除无用缓存」可清理已删除方案、作图卡片、对话等遗留的临时文件。先备份本地资料库；需要迁移时，请使用内置数据目录工具。

报告问题时可在「反馈」选择私密表单或公开 GitHub Issue。私密表单由反馈服务转交开发者；公开 Issue 需到 GitHub 确认后发送。提供版本号、复现步骤与必要的截图，避免附上 API Key、患者信息或未公开研究资料。
