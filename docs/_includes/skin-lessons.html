41切换皮肤与识别界面图标

  1. 打开左侧导航的「皮肤」。第一次使用时默认是「经典」，同一行还可选择「江山青」「深海蓝」「香槟金」和「绛红」。
  2. 点击预览卡立即应用。带描边和勾选标记的卡片代表正在使用的皮肤。切换后可回到收藏、期刊目录或 AI 部署检查导航、按钮和卡片配色。
  3. 自行制作或导入的皮肤显示在下方「DIY 皮肤包」区。点击它可让桌面背景连续铺过侧栏与内容区。功能卡片按皮肤包里的卡片图显示，文字附近会保留淡化层。文章结果卡和课题组角色卡保持便于阅读的样式。

42用本地图片制作皮肤

准备一张适合宽屏的桌面图和至少一张卡片图。多张卡片图可以分配给不同的功能卡片，顺序可在保存前调整。

  1. 在「皮肤」点「DIY 皮肤包」，填写名称。将本地图片拖入左侧「待选图片」，也可点「添加图片」浏览文件。
  2. 在待选列表单击一张图，点「设为桌面背景」。右侧会显示预览。要替换时选另一张图，再点一次同样的按钮。
  3. 选中一张或多张图并点「加入卡片背景」。按住 Ctrl 或 Shift 可选多张。用拖动或「前移」「后移」改变列表顺序，「移除卡片背景」会从列表移除所选项。
  4. 检查一张桌面背景和卡片列表后，点「保存并应用」。此流程在本机完成，适合用自己的插画、照片或已准备好的配色素材。

43用 AI 制作皮肤

选择模型并准备创作素材

  1. 在「皮肤」点「AI DIY皮肤包」，填写皮肤名称。文字模型将要求整理成画面描述，可以选择可用的个人通道、课题组授权或本机 Codex。
  2. 选择生图模型。皮肤生图可使用已在「AI部署」开启的个人 API 通道或 Codex 本机连接。文字模型与生图模型可以来自不同服务商。
  3. 描述你想看到的主体、构图、风格与配色。例如「写实的近距离自然景色，包含花草、鸟和树，留出文字空间」。还可拖入最多 6 张参考图，或点「添加参考图」。
  4. 查看窗口底部的输入说明。有图像输入能力的生图模型会接收参考图，用其中的主体与风格进行二次创作。参考图多于模型上限时，软件会合成一张拼图提供给模型。只接收文字的模型会继续根据绘图描述生成。参考图在应用内仅记录文件路径，实际提交的内容会由所选服务商处理。
{% include guide-shot.html id='skins-ai-form' %}

后台生成、核对并应用

  1. 点「生成皮肤预览」。软件依次生成 1 张桌面背景和 8 张独立卡片背景。进度区提示当前阶段，期间可以最小化窗口，回到主界面继续工作。
  2. 再次点主界面「AI DIY皮肤包」可恢复原窗口并查看任务。可用「取消 AI 任务」停止后续请求，已被服务商接收的请求仍可能产生费用。
  3. 完成后，左侧核对桌面图，右侧逐张查看卡片背景，可按需要拖动或用「前移」「后移」排序。点「保存并应用」后，皮肤包出现在 DIY 区。

创作描述与参考图遵循所用服务商的内容审核规则。若提示审核拒绝，先查看提示指向绘图描述、参考图还是生成结果。若提示请求参数无效，则到「AI部署」核对模型、推理接入点和参考图格式。

44排序、导入、导出与删除皮肤包

调整皮肤包顺序并批量导出

  1. 在 DIY 区拖动整张皮肤卡片，或右键选择「前移」「后移」。此处调整的是皮肤包在列表中的位置。卡片背景的顺序在制作预览中调整。
  2. 点击「导出皮肤包」。在窗口中勾选一个或多个自定义皮肤，可使用「全选」和「取消全选」。点击「选择保存位置」，将所选皮肤保存到同一个 ZIP。
{% include guide-shot.html id='skins-export' %}

预览 ZIP，选择缓存的皮肤

  1. 点「导入皮肤包」选 ZIP，也可直接将 ZIP 拖入主界面的「皮肤」页。窗口会预览压缩包里的皮肤封面、名称和卡片图数量。
  2. 勾选要保留的皮肤，再点「缓存所选」。返回 DIY 区点击相应卡片即可应用。
  3. 删除时先选中相应 DIY 皮肤，点「删除皮肤包」并确认。软件删除本地缓存的该款皮肤，并切回经典。已导出的 ZIP 可用于日后重新导入。
