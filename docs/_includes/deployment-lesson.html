21配置 AI、本机 Codex 与课题组

在左侧打开「AI部署」。如果你用自己的 API Key，从个人模型设置开始；有 PI 分发的访问 ID，先从课题组面板登录；使用自己的 ChatGPT 账号，则走本机 Codex。文字分析和模型图分别配置。

文字模型本机 Codex登录入口课题组管理绘图通道

文字模型卡片：配置、开启和查看用量

  1. 在 DeepSeek、ChatGPT · OpenAI API、Kimi 或 GLM 卡片点「设置」。个人直连填写该服务商的 API Key；ChatGPT 网页会员和 OpenAI API 账单分别管理。
  2. 有课题组授权时，可在「调用通道」选「优先课题组授权」。该页会切到这一通道的配置，学生不需要填 PI 的 Key。如果优先通道不可用，只有另一条通道已配置且可用时才会回退。
  3. 刷新目录、选模型、设推理强度、保存并启用。然后返回卡片核对「当前」和「优先」通道，再在具体任务顶部选这个模型。图像专用通道不会出现在文字分析列表。

文字模型卡片与设置窗口：逐项说明
模型名称／小箭头
展开或收起卡片，查看本地调用次数、确认的输入／输出 Token、缓存输入和上次调用；卡片显示的是当前通道，也会单列优先通道。本机统计不等同于整个服务商账户账单。
设置／调用通道／启用所选通道
设置只编辑所选服务商。切换通道会读回对应模型和选项；勾选启用并保存，才让该配置可用于任务。课题组顶部的「未单独设置时的默认通道」只为没有单独指定的服务提供默认值。
API Key／显示／隐藏
个人直连填官方平台的 Key，不加 Bearer 前缀。已加密保存的 Key 留空可沿用；「显示」只切换输入框中当前输入内容的可见性，不会自动读出旧 Key。编辑完切回「隐藏」。
联网刷新模型／选择模型／推理强度
用当前通道和 Key 查询目录；换 Key 后先刷新，再从实际下拉项选模型。列表出现不保证账户能实际调用。推理档位只显示当前模型支持的设置；没有可调档位时用默认。
保存设置／关闭／删除已保存密钥
「保存设置」提交更改；「关闭」放弃尚未保存的编辑。个人页「删除已保存密钥」清除该通道本地配置；课题组页的对应按钮叫「清除当前模型选择」，不会删除 PI 服务商账户的 Key。
开启模型／关闭模型
控制当前配置能否被任务选中。首次没选模型时先到设置完成配置；关闭模型不会注销课题组、删除 Key 或取消已提交的任务。
刷新余额／打开账户用量或账单
提供余额接口的卡片可刷新当前账户余额；换通道后重新查询。没有返回值不等于 0，网络超时也可能已计费。用账单按钮到服务商核对；学生应在「我的用量」查看当前电脑的记录；全账户费用由 PI 对照服务商账单。

本机 Codex：登录、刷新模型和推理强度

  1. 点「ChatGPT Codex · 本机连接」的名称展开卡片，再点「使用 ChatGPT 登录」。在打开的官方浏览器页面授权，返回客户端等状态更新。
  2. 「检测 / 刷新模型」读取本机 Codex 组件和当前账号可见的模型。列表没更新时，先关闭已打开的设置框，刷新完成后再打开。
  3. 「设置」选择文本模型及其推理强度；「保存设置」写入选择，「关闭」放弃未保存的编辑。图像工具模型由官方本机组件管理，「图像推理强度」没有单独的可调档位。保存后点「开启模型」，回到任务窗口选择本机 Codex。

本机 Codex 使用自己的 ChatGPT 会话，不使用个人 API Key 直连设置，也不随 PI 的课题组授权共享。

先选登录入口：PI 和学生使用同一个规则

中国大陆网络请用「默认 · biomedreader.cn」。这是在阿里云注册的自有域名，作为国内可直接访问的课题组入口。「备用入口 · workers.dev」是 Cloudflare Workers 的备用域名，在中国大陆一般无法直接访问；只有当前网络能连通它时才用。两个入口只改变课题组连接地址，账号、授权、模型费用和设备名额相同。

选择入口后，由软件连接课题组服务；成功登录后的课题组请求会继续使用本次选择的入口。需要切换时，先通过原入口完成退出，再重新打开登录窗口选入口。若连接超时，先检查网络与入口；若明确提示「访问 ID 无效」或「已停用」，应核对完整 ID 或联系 PI。

PI 登录／建立课题组

  1. 点「PI登录」，在「登录入口」选择可用地址，再从「服务商」选这个 API Key 所属的平台，粘贴你自己的 Key。
  2. 想同时授权另一平台时点「同时绑定另一个服务商Key（可选）」，每个服务商只填一项；留空不绑定。不着急时也可先登录，再在管理窗口增加。若提示部分服务商绑定失败，可在管理窗口单独补配。
  3. 点「登录（剩余次数）」并等待身份验证。登录成功但提示 Key 待同步时，可在管理窗口核对服务商配置；无需为查看目录发起生成任务。按钮中的数字是当天剩余登录次数，不是设备数；验证不调用生成模型。点「关闭」可以结束本地等待。

学生登录／退出课题组登录

  1. 点「学生登录」，选择入口，粘贴 PI 私下发给你的完整学生访问 ID。成员表里的普通 user_id 不是登录凭据；学生也不需要输入 PI 的 API Key。
  2. 登录时会提交本机网卡 MAC 地址，用于登记设备。成功后在面板确认角色和当前通道。打开「可用AI模型」核对授权，进入对应模型设置选模型、保存并开启。「我的用量」显示该账户在这台电脑上的记录。
  3. 同一个 ID 最多同时登记两台电脑。换设备前在旧电脑点「退出课题组登录」，等服务确认解绑；断网时软件仍保持学生登录，恢复连接后再试。切回个人 Key 只改变调用通道，不释放名额。PI 停用优先于设备限额，遇到停用应联系 PI。

学生与用量管理：创建、停用、同步和导出 ID

PI 登录后点「学生与用量管理」；学生点「我的用量」。两个窗口都能看本账户在本机近一年的用量日历，成员管理仅对 PI 开放。日历悬停可看每日明细，「服务商来源」决定统计哪一平台；「刷新用量」重读本地数据，不等于查询服务商余额或其它电脑的用量。

PI 管理按钮与弹窗：逐项说明
新增学生／复制完整访问ID
输入姓名或备注创建。弹窗显示完整 ID，点击复制后私下交给对应学生；关闭弹窗后可从成员行再次导出。
导出 PI ID／导出学生 ID
在相应行打开导出窗，再点「复制ID」。PI ID 用于识别课题组身份，不代替 PI 用服务商 Key 登录；学生须使用完整访问 ID。不要把完整凭据粘贴到公开表格、Issue 或截图。
停用学生／启用学生
先选中学生行再确认。停用会阻止该学生使用课题组服务；启用是恢复该身份的访问许可，不会替他登录或增加设备名额。
重置访问 ID／重置并导出新 ID
重新签发完整访问 ID，旧 ID 和会话会失效。只在需要更换凭据时使用；把新 ID 单独交给学生。
配置课题组Key／确认提交服务端
选服务商并提交与其匹配的 Key。此操作更新课题组授权，并会再同步。若某平台未出现在目录，先核对该平台绑定，然后刷新模型目录。
删除学生信息／关闭
删除会永久移除该学生并使访问 ID 与会话失效；如果只是暂时暂停权限，选「停用学生」。关闭管理窗口只结束当前窗口，不退出课题组。

可用 AI 模型、余额和本地 Key 窗口

可用AI模型／刷新模型目录
PI 和学生都可查看已授权平台、返回的模型 ID 与用途；「仅目录」不等于该模型有付费调用权限。点「刷新模型目录」重新取元数据，不会请求生成。配置或开启模型仍需回 AI 部署卡片。
余额查询／一键刷新全部余额／打开用量或账单
PI 可集中查询支持余额接口的平台。某平台显示「未接入」时用该行的官方账单入口；同平台多个模型可能共用一个余额。学生没有 PI 的余额管理权限。
查看API keys／复制API Key
只对登录中的 PI 显示其本地加密缓存的 Key，页面不明文展示。点击某一行会把该 Key 复制到系统剪贴板；只在可信环境使用。无缓存时回管理窗口核对绑定。

模型图使用独立绘图通道

  1. 在主设置「AI模型图生成」选择阿里云百炼、火山引擎方舟、GLM-Image、AI 模型可调用的绘图工具，或跳过。文章有可用原图时优先沿用，绘图失败可以先保存已生成的文字。
  2. 在方舟或百炼绘图卡片点「设置」；GLM-Image 可从 GLM 模型设置进入。选「调用通道」，勾「开启此绘图通道」。个人直连填所属平台 Key，课题组授权使用已绑定的服务商。
  3. 「图像模型 / endpoint ID」选择预置名称或填实际 ID；百炼还需选择 Key 对应的北京或新加坡区域。可用时点击「联网刷新图像模型目录」，它查询目录而不生成图片。推理强度由图像接口决定，设置完成点「保存设置」。
  4. 卡片「开启模型／关闭模型」控制是否可用于模型图；展开卡片可看当前通道或点「打开用户用量／账单」。余额正常也可能因模型未开通、区域不符或服务超时而失败，先查错误发生在哪个通道再重试。
