刊禾 Biomed Reader 隐私政策

适用于 Biomed Reader 2.2.2。更新于 2026 年 11 月 23 日。

本地资料和设置

文献收藏、笔记、关联文件路径、作图项目、缓存及你保存的结果通常存放在本机。你可以在软件设置中查看数据目录、清理缓存和管理备份。Windows 版本使用系统数据保护机制保护部分本地保存的凭据。

联网检索和 AI 服务

使用联网检索时，检索词会发送给你选用的来源，例如 PubMed、bioRxiv 或 medRxiv。打开外部文献、网页或下载链接时，由对应网站处理访问请求。

使用在线 AI 时，当前任务所需的提示、对话上下文及你选用的文献文字、图像或图表数据可能会发送给所选模型服务商。个人通道向所选服务商发送请求，课题组通道经课题组服务转发。你可以选择模型和输入材料，AI 作图窗口也提供原始预览及素材的发送选项。使用 Codex 本机连接时，由你配置的 Codex 客户端按其服务设置处理输入。第三方服务依其政策处理资料。

课题组账号和设备绑定

课题组服务处理 PI 提供的服务商信息和密钥、PI 设置的成员信息、设备绑定、会话和调用用量，用于验证账号、管理授权和显示用量。服务器对保存的服务商密钥进行加密。

学生登录时，软件经 HTTPS 发送访问 ID、用于设备绑定的网卡 MAC 地址和登录所需信息。服务端为设备绑定保存带密钥的摘要，用于限制同一学生 ID 同时使用的设备数量。联网退出成功后，服务解除该设备的绑定。成员信息及访问权限可联系课题组 PI 核对、修改或停用。

反馈与数据请求

你主动发送私密反馈后，反馈服务会接收问题类型、标题、正文、软件版本、操作系统版本、提交编号及你自愿填写的联系方式。私密反馈通过 Cloudflare D1 处理和保存，邮件通知通过 Resend 发送给开发者。反馈服务使用访问 IP 的带盐摘要进行限流。D1 中的反馈记录配置为在 15 天后清理，开发者邮箱中的副本另行保存。

若选择 GitHub Issue，软件会打开预填的问题页面，由你在 GitHub 确认提交。GitHub 上的问题可能公开显示。请通过软件内的私密反馈咨询数据处理，或提出访问、更正、删除请求。一般使用问题也可通过 Biomed Reader GitHub Issues 联系开发者。
