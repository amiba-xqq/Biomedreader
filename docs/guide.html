GETTING STARTED & EVERYDAY USE

01安装与升级

首先在下载页面选择正确的系统与芯片版本。

  1. Windows 安装版：运行 EXE 安装程序。支持 Windows 10/11 的 64 位系统。
  2. Windows 目录版：完整解压 ZIP，进入 BiomedReader_2.1_Portable_x64 文件夹运行 BiomedReader.exe，保留 _internal。需要 Word 插件时按插件安装步骤注册。
  3. macOS：M 系列与 Intel 使用不同的 DMG。支持 macOS 12 及以上，将应用拖到“应用程序”。
升级前先备份。先在旧版设置中备份完整本地数据，再退出 Biomed Reader 和 Word 后升级。新版沿用数据兼容标识，缓存、方案、收藏与 PDF 关联继续使用。macOS 若出现开发者提示，请参考仓库安装说明。

02第一次打开与界面导航

左侧四个入口分别负责不同的工作：

  • 关键词方案：保存检索条件，进入某个课题的缓存与结果页面。
  • 收藏文章：管理收藏分组、标签、笔记与 PDF。
  • 期刊目录：维护内置和自定义期刊范围。
  • 设置：调整默认视图、检索范围、JIF 年份、字体和本地数据。

首次使用时先检查设置中的预印本来源范围与最近年限，然后创建关键词方案。

03创建关键词方案与表达式

  1. 点击“添加关键词组”，输入便于识别的方案名称。
  2. 输入关键词或布尔表达式。方案名称用于卡片与收藏分组，检索表达式决定实际查询。
  3. 选择本方案的数据源、候选数与默认排序，保存后即可从主页卡片进入。
R-loop OR "DNA-RNA hybrid"

AND 连接需要同时满足的概念，OR 合并同义词，英文引号标记短语，括号组织条件。不同网站对表达式的解析可能不同，复杂查询建议在对应官网核对。

PubMed 专属字段标签建议只用于仅 PubMed 的方案。主页关键词卡片可拖动排序，默认每行五张，也可调整宽度。

04数据源、年份与期刊筛选

在“编辑方案”中选择仅 PubMed、仅预印本官网，或两者。预印本具体使用 bioRxiv、medRxiv 还是两者，在设置中选择。

  • 文章类型：Research Article、Review 等可多选，仅用于 PubMed。
  • 发表年份：上下限分别设置，包含边界。支持直接输入或下拉选择，最大年份跟随本地电脑年份。
  • 期刊范围：选择一个或多个期刊目录，多个目录取并集。
  • 最低 JIF 与期刊目录：仅限制 PubMed，不限制预印本文章。

检索范围在设置中调整

PubMed 可选默认范围或标题与摘要。预印本可选默认、标题与摘要、全文、全文与标题摘要。预印本最近年限默认两年，并与方案年份取交集。全文命中也可能来自参考文献等位置。

05候选数与三种排序

PubMed 与预印本候选数分别设置，新方案均默认为 0（不限）。数量越大，首次完整搜索通常越久。同时启用 bioRxiv 与 medRxiv 时，各站点分别使用同一个预印本候选数。例如设置 20，两个站点各获取至多 20 篇。

排序 阅读顺序与预印本检索
最新发表 按日期优先，预印本官网对应 Newest first。
最相关 按来源排名与相关性信息，预印本官网对应 Best Match。
综合最佳 预印本先按 Newest first 获取候选，再结合相关性和新近程度本地排序。

综合最佳使用 72% 归一化相关性与 28% 时间新近度，时间权重约每 180 天减半。相关性依据已有标题、摘要和关键词计算，不能视为跨网站统一的官方评分。

有限候选集不保证覆盖全部历史中最相关的文章。候选数、年份、期刊、文章类型和收录时间差异，都会影响软件与官网结果的对应关系。

06首次、增量与完整检索

  1. 首次联网刷新：为新方案完整建立缓存基线。
  2. 后续普通刷新：检索条件不变时，从对应来源上次成功刷新日到本地今天，按日检索并去重合并。
  3. 完整检索：主动勾选该选项，重新核查全部条件范围。修改实际检索条件也可能需要重新建立基线。

各来源分别保存成功状态。一个来源失败，不要求已成功来源重复完整检索。缺少有效成功检查点的旧缓存，可能需要一次核验；PubMed 会复用已有摘要并补取缺失记录。

检索结果分批保存。取消或部分失败后，仍能查看本次已缓存的新文章。失败不会推进整体成功刷新时间，也不会改变其它关键词卡片的刷新时间。

严格按日增量的边界：PubMed 依据发表日期，预印本依据版本发布日期，可能遗漏晚收录的旧文章。需要重新核对时使用完整检索。刷新时间与间隔以本地电脑时间为准。

2.1：全部联网刷新

  1. 回到“关键词方案”，先拖动卡片排好顺序，再点击右上角全部联网刷新。
  2. 软件按当前卡片从左到右、从上到下的顺序，逐个处理方案；正在检索的卡片显示进度状态。
  3. 首次刷新的卡片建立完整缓存。已有有效成功检查点、检索条件未改变的卡片，按各来源上次成功日期到本地当天增量检索；它不是对每个卡片强制“完整检索”。
  4. 某个来源或方案失败会记录结果并继续队列；已取得内容保留。需要停止时点击取消全部刷新，取消当前检索及后续队列。

开始全部刷新前请等待正在运行的单方案检索结束。遇到预印本验证窗口，仍需人工完成验证；可最小化该窗口等待检索。

07预印本官网验证与取消

预印本关键词检索由对应的 bioRxiv 或 medRxiv 官网完成。弹出的搜索窗口可以最小化，搜索会继续。

  • 出现人机验证时，恢复窗口并手动完成验证，软件不会自动破解验证码。
  • 如果网站提示请求过多，请等待自动恢复，频繁重新加载可能延长等待。
  • 关闭官网窗口会取消这次官网检索。主结果页也可使用“取消检索”。
  • 首次大量结果可能需要多页读取，比在官网仅查看第一页更耗时。

网站改版、限流或临时不可用都可能影响检索。遇到问题先保留缓存，再检查来源和筛选条件。预印本通常尚未完成同行评审，引用前请核对正式发表状态。

08表格、卡片与默认展现形式

默认展现形式：在设置中选择“关键词方案默认展现形式”：宽松的嵌入式卡片、紧密的嵌入式卡片、表格。默认紧密卡片。

每次重新打开软件，各方案从设置中的默认形式开始。进入方案后仍可临时切换表格、卡片及密度，临时选择仅在本次运行有效，不修改全局默认值。

  • 表格：拖动列边界调整宽度。先加载部分行，向下滚动继续查看。
  • 嵌入式卡片：展示期刊、标题和摘要。点击展开摘要查看全文本，底部使用上一页或下一页，每页 24 篇。
  • 卡片密度：紧密缩小卡片，实际每行数量随窗口宽度变化。关键词卡片模式记录浏览页面和位置。
  • 预印本：标题浅红加粗。缺失摘要按当前页面后台补取，尚未获取的摘要可能暂时无法离线查看。

09缓存来源与隐藏文章

结果页面的“检索源”用于筛选已缓存的 PubMed、bioRxiv、medRxiv 文章，可以多选。它不会更改方案的联网检索数据源，也不会删除其它来源的缓存。

  1. 对不想继续看到的文章点击“隐藏”。表格模式先选择文章，再使用对应按钮。
  2. 需要恢复时打开“隐藏设置”，勾选显示隐藏文章。
  3. 对该文章点击“取消隐藏”，再关闭显示隐藏的选项即可恢复普通展示。

隐藏只作用于当前关键词方案，重启和刷新后仍保留，不删除缓存、收藏或 PDF。缓存总数仍包含隐藏文章，当前显示数量会根据筛选变化。

10文章详情、DOI 与已读标记

点击文章详情可阅读完整摘要、作者、DOI、期刊与已录入的 JIF，也可记录标签和笔记。已缓存内容可以离线查看，DOI 网页本身通常需要联网。

“打开 DOI / 文章界面”会调用默认浏览器，详情文字保持不变。点击后，这一轮结果中的对应文章显示访问标记，字体颜色变淡，卡片背景始终保持白色。

联网刷新重置 DOI 访问标记，保留收藏、笔记和隐藏状态。软件不会在刷新或打开详情时自动寻找模型图或抓取文章首图。

11复制引用、期刊样式与卷页信息

  1. 打开文章详情，点击导出 / 复制引用。
  2. 在弹窗中选择期刊样式，或先在“设置 → 参考文献格式”选择默认期刊；默认 Cell，支持下拉选择和输入关键词匹配。
  3. 等候必要的元数据补全，检查引用中的作者、年份、期刊、Volume（卷号）、Issue（期号）、Pages（页码或文章号）及 DOI。
  4. 点击复制引用，引用窗口关闭并提示“复制成功，可以粘贴”，再粘贴到所需位置。

什么时候联网，什么时候使用缓存？

  • Volume 或 Pages 任意一项仍缺失：每次点击导出/复制引用都即时尝试补全，不等待 24 小时。
  • 两项都已缓存：直接使用已有信息，不再为补全卷页发起请求；已补齐的数据可离线使用。
  • 在线优先发表或预印本可能尚未分配卷页，网络也可能临时不可用。软件保留已有引用，未分配字段留空，不编造数值。

元数据优先通过 PubMed 获取，必要时按 DOI 补充。单篇引用格式对未匹配独立样式的期刊会明确标注出版社通用后备样式。复制引用得到文字；需要在 Word 中自动编号和维护文末列表，请使用下面对应平台的写作流程。

12收藏分组与本地 PDF

在哪个关键词方案收藏，文章就进入同名收藏分组。删除关键词方案后，收藏分组继续保留。支持自定义分组、拖动排序，将一篇或多篇文章复制或移动到其它分组。

收藏文章可按分组或全部展示，并按发表时间或收藏时间排序。收藏时间按最近收藏优先：表格从上到下由新到旧，卡片按相应阅读顺序排列。组内支持表格、嵌入式卡片和卡片密度选择。

链接与打开原文

  1. 先收藏文章，在收藏文章详情中点击“链接文章”。
  2. 浏览并选择已下载的 PDF，软件复制到当前数据目录的 paper 文件夹，以文章标题命名。
  3. 链接成功且文件存在时，“查看原文”可点击，由系统默认 PDF 阅读器打开副本。
取消收藏与删除：所有入口都会弹出确认窗口。确认后从全部分组取消该文章的收藏，并清除 PDF 链接、删除不再使用的 paper 内副本；原始下载文件与文章缓存保留。详见批量取消收藏与确认规则。

13搜索已收藏文章

这项搜索只查找已有收藏，不会联网检索新文章，也不会读取 PDF 全文。

  1. 进入收藏文章，点击搜索已收藏文章…。
  2. 在弹窗中勾选一个或多个收藏分组；可使用全选或全不选，再输入需要查找的关键词。分组和关键词均为必填。
  3. 点击确定。软件在所选分组的标题、摘要、作者、期刊、DOI、PMID、标签和笔记中匹配关键词。
  4. 分组展示：只保留包含匹配文章的分组卡片，点进后也只展示匹配文章。不分组展示：合并去重后只显示符合条件的文章。
  5. 可继续选择表格或嵌入式卡片以及排序方式；点击清除搜索恢复全部收藏。

多个词用空格分隔时，需要全部匹配；完整短语可用双引号，例如 "DNA repair" ATM。这里不使用 PubMed 的 AND / OR 检索表达式。筛选不会删除或移动文章，也不会改变分组归属。

筛选范围：搜索只覆盖所选分组中的本地缓存。当前搜索条件在本次打开期间保留，重新启动后需重新设置。

14批量取消收藏与删除确认

  1. 在收藏文章页面点击批量取消收藏…，打开分组与文章双列选择窗口。
  2. 左侧勾选一个或多个分组，右侧只显示这些分组的文章，并自动勾选新增所选分组的文章。
  3. 在右侧逐篇调整勾选，也可使用全选可见文章或全不选。最终以右侧全部已勾选项为准，包含被弹窗内搜索暂时隐藏的勾选项。
  4. 点击批量取消收藏，阅读确认弹窗。默认选择为保留收藏；只有点击确定取消收藏才会实际执行。
  5. 处理完成后查看结果；如部分 PDF 被占用无法删除，对应文章的收藏、分组和 PDF 链接保留，其余成功项正常取消。关闭占用文件的阅读器后可重试。
所有取消收藏入口采用相同规则。关键词方案中的收藏按钮、文章详情和批量取消都会先确认。确认后，文章会从全部收藏分组移除；已链接的 PDF 会解除关联，当前数据目录 paper 中不再被其它文章共用的 PDF 副本会被删除。paper 外的原始 PDF、检索缓存和笔记保留。操作前请确认要删除的对象。

批量取消与正在进行的 PDF 导入、分享操作不能同时执行。打开了 PDF 选择窗口时，请先关闭该窗口。若文章已用于 Windows Word 插件，之后更新引用时还会按原收藏分组的成员关系重新核对，详见Word 插件教程。

15检查软件更新与安装新版

  1. 进入设置 → 软件更新，点击检查软件更新，保持联网。
  2. 软件读取官网版本。当前版本与官网相同，会提示已是最新版本，无需更新；不会下载旧版本。
  3. 发现更高版本时，自动选择对应系统的 GitHub 安装包：Windows x64 EXE，或 macOS Apple Silicon / Intel DMG。选择保存位置后开始下载。
  4. 等待进度完成。软件会验证文件大小和 SHA256；取消或校验失败时，不覆盖已有文件。
  5. 下载完成后，先备份本地数据，退出 Biomed Reader 和 Word，再手动运行安装程序；Mac 打开 DMG 后替换应用。此功能不会自动安装。

软件更新区域下方的官网链接可用默认浏览器打开。遇到网络问题，也可前往下载页手动选择安装包。

同版本修订需手动下载。本次发布版本号仍为 2.1。已安装旧修订的 2.1 与官网版本号相同时，检查更新会提示无需更新；请在下载页手动下载并覆盖升级本次修订包。

16批量收藏本地 PDF

适合将已下载的一批 PDF 整理进文献库。软件不下载论文，而是读取本地 PDF 的首页完整标题，通过 PubMed 找到可靠匹配并关联原文。

  1. 进入“收藏文章”，点击批量收藏 PDF…。
  2. 点击“选择 PDF 文件…”多选或单选文件；也可将一个或多个 PDF 拖进选择框。选择窗口独立显示，主窗口最小化后，仍可从资源管理器或 Finder 拖入文件。
  3. 必须勾选一个或多个期刊目录，多个目录取并集。目录中没有的期刊不参与匹配；覆盖不全时先扩充自定义目录。
  4. 必须选择目标收藏分组，可选择已有分组，或勾选新建并输入不重复的名称。
  5. 点击“开始识别与收藏”。程序识别首页较大字号的完整标题，包括换行，并结合 DOI 核对候选。仅通过 PubMed 检索，检索范围跟随设置，不使用年份和 JIF 限制，但始终保留所选期刊目录范围。
  6. 确认匹配后加入所选分组，PDF 副本存入当前数据目录的 paper 并自动关联。打开该收藏详情，点击“查看原文”即可用默认 PDF 阅读器查看。

查看进度、失败名单和取消结果

目标分组卡片显示进度，例如“共 10 个 PDF，已完成 2 个”。全部成功时提示完成；部分失败时显示文件名与原因，可点击“复制未成功的 PDF 文件名”或“导出文件名单…”。复制后报告继续保持打开，需手动关闭。

点击“取消 PDF 导入”会保留已成功收藏和关联的文件，尚未完成的项目在报告中列出。同篇文章按标识合并；原始下载 PDF 不会被移走或删除，已有链接也会尽量沿用。

匹配不到时：检查期刊是否在所选目录、PubMed 是否收录、首页是否为封面或扫描图。当前未内置 OCR；无法提取或核实完整标题时会报告失败。可以先按标题手动检索、收藏，再通过“链接文章”选择 PDF。

17Windows：Biomed Reader Word 插件

适用于 Microsoft Office 2021 及以上的桌面版 Word。Windows 安装版会注册当前用户的插件；完整目录版提供手动注册脚本。Mac 的操作见下一章。

安装与打开工具栏

  1. 关闭 Word 后安装或升级 2.1，重新打开 Word，查找 Biomed Reader 选项卡。
  2. 目录版先完整解压到固定位置，关闭所有 Word 窗口，运行 RegisterWordAddin.cmd 后重新打开 Word。移动程序文件夹后重新注册；需要取消该目录的注册时使用 UnregisterWordAddin.cmd。
  3. 插件未显示时，在 Word“文件 → 选项 → 加载项 → 管理：COM 加载项 → 转到”中确认 Biomed Reader 已启用。目录版与安装版同时存在时，最近注册的位置决定插件连接哪一份程序。
  4. 点击插件的打开 Biomed Reader；也可先手动启动软件并等待本地文献库载入。

选择文章并插入引用

  1. 在 Biomed Reader 的“收藏文章”进入目标分组，选中要引用的文章，表格或卡片均可。
  2. 切回 Word，将光标放到正文需要引用的位置，不要放在文末参考文献列表内。
  3. 点击插件插入引用。程序按所选样式插入引文标记，并在文末维护参考文献；继续插入其它文章时会重新排列编号。
  4. 引文样式决定使用上标、括号编号或其它标记。默认 Cell；样式改变时不要手动改数字，使用更新命令统一处理。

更换期刊格式、字体与更新文献

在插件“参考文献格式”的期刊框中下拉选择，或点击选择期刊…输入部分名称筛选。Word 列表限于 NC 扩选与已核实 EndNote 样式的交集。选择后点击更新引用文献应用到全文；软件设置中的单篇复制引用样式，与 Word 当前文档的期刊选择是两个入口。

点击参考文献字体设置字体、字形和字号。默认 Arial、常规、五号（10.5 磅），作用于文末参考文献和正文引文标记；上标继续保持上标，正文普通文字的字体不受影响。旧文档缺少卷页时，更新引用也会尝试从本地库补齐已有信息。

更新前请保存稿件副本。引用记录绑定最初选择文章时的收藏分组。若文章已从那个原分组移出，点击“更新引用文献”会删除对应引文并重排编号，即使它仍在其它组收藏。文档来自其它本地文献库时，应先连接原文献库再更新，以免核对错误。

导出给 EndNote 接管

  1. 先安装并启用 EndNote 桌面版及 Word 的 Cite While You Write（CWYW）插件。
  2. 在含 Biomed Reader 引文的稿件中点击导出为 EndNote，选择 .docx 或 .doc。
  3. 插件生成文档副本，将引文交由 EndNote 格式化，保存嵌入文献记录与文末参考文献，原稿保持不变；这不是仅导出 RIS。
  4. 在导出副本中使用 EndNote 的“Update Citations and Bibliography”继续维护；需要独立文献库时，使用 EndNote 的“Export Traveling Library”。

若插件暂时无法连接，请先确认 Biomed Reader 已启动、使用的是原本的本地文献库，并在升级后完整退出再打开 Word。导出失败时保留原稿，检查 EndNote CWYW 是否正常启用。

18Mac：Word 文档导出与 EndNote 接管

Mac 2.1 使用文档互通流程，在 Biomed Reader 中导出引文集合，再由 Mac Word 中已安装的 EndNote CWYW 接管。此版不安装 Mac 原生 Biomed Reader Word 工具栏，也不自动根据收藏分组变化改写已有稿件。

  1. 打开“收藏文章”，选择目标分组或全部收藏，点击导出 Word / EndNote…。
  2. 在导出窗口勾选文章，选择期刊样式；列表同样为 NC 扩选与已核实 EndNote 样式的交集，可输入关键词筛选。
  3. 导出 .docx。文件包含 EndNote 引文域、各篇嵌入的文献记录、卷页信息和文末参考文献，默认字体为 Arial 常规五号。
  4. 用桌面版 Mac Word 打开，使用 EndNote 的 Update Citations and Bibliography 更新引用与格式。EndNote 若没有相应样式，请安装或选择可用样式。
  5. 写入自己的稿件时，从引文集合中复制所需引文域，保留 Word 域格式，再由 EndNote 更新编号与参考文献。不要使用“仅保留文本”或将引文转换为纯文本。
  6. 需要建立 EndNote 文献库时，在 Word 的 EndNote 工具中选择 Export Traveling Library，导出嵌入记录。
已验证范围：跨平台文档结构及 EndNote 重建参考文献已在 Windows Word / EndNote 中测试，Mac 应用已通过双架构构建、部署目标和启动检查；Mac Word / EndNote 的实机端到端联动尚未完成验证。请先用文档副本试用。应用支持 macOS 12，不代表任意 Word 或 EndNote 版本也支持该系统，版本匹配以各软件要求为准。

19期刊目录与 JIF 年份

内置 IF 6-10、IF 10-20、IF 20-500、NC精选、NC扩选五个目录。IF 三组按 2025 年已录入 JIF 固定划分：6≤JIF<10、10≤JIF<20、20≤JIF≤500。

  1. 创建自定义目录，或将内置目录复制为自定义目录。
  2. 输入部分期刊名称或 ISSN，按名称或 JIF 排序，输入 JIF 上下限筛选。
  3. 勾选“只显示已选择的期刊”检查成员，命名并保存。全选与全不选只针对当前筛选结果。

设置中的 JIF 年份默认本地年份减一，可选 2010 年至当前年。只有已录入对应年度数据时才显示数值，缺失留空。切换显示年份不会重新划分 IF 三组的成员。

软件不在线补全 JIF，不调用 Clarivate Journals API。NLM 公开目录收录不等同于 SCI 认证，指标以本地已录入年度数据为准。

20分享、备份与移动数据目录

分享收藏与期刊目录

收藏打包时先选择一个或多个分组，右侧只展示这些组的文章并默认勾选。最终只导出右侧已勾选文章，可选择包含已链接 PDF。接收者使用“读取分享压缩包”，导入文章、分组、笔记与 PDF 关联。

期刊目录也可选择多个卡片导出 ZIP。导入同名目录时追加“_已重复”，避免覆盖原目录。

备份整个本地资料库

“备份本地数据（ZIP）”导出整个数据目录，包含数据库、缓存和 paper 下的 PDF。单独导出收藏分享包不能代替完整备份。

  • Windows 默认：%LOCALAPPDATA%\OrangeReader\BiomedLiterature
  • macOS 默认：~/Library/Application Support/OrangeReader/BiomedLiterature
  • 移动本地数据目录：选择专用空目录，按提示退出迁移，验证完成后删除原数据并使用新路径。操作前先备份。
  • 链接本地数据目录：选择已有文件夹本身，其中应直接包含 biomed_literature.sqlite3，结构不正确会拒绝链接。

路径选择窗口支持在 Look in 中输入或粘贴路径，按 Enter 进入后再选择目录。字体和布局可在设置中自动适配屏幕或整体缩放，软件保持浅色界面。

21常见问题与使用注意

为什么结果与 PubMed 或预印本官网不同？

检查表达式、数据源、范围、年份、文章类型、期刊和候选数，并确认检索完成。多个来源合并、不同的排序方式与收录延迟，都可能产生差异。

为什么新方案第一次搜索比较慢？

第一次需要建立基线，大候选集通常需要读取多页结果。预印本官网可能还会要求验证或限流。后续条件不变时按来源检查点进行日级增量。

断网后能查看哪些内容？

能查看已经缓存的文章标题、摘要、收藏和笔记，也能打开已链接的本地 PDF。尚未下载的摘要、DOI 网页或尚未取得的全文需要联网。

为什么重启后卡片形式恢复了？

这是当前设计：重启采用设置中的关键词方案默认展现形式。要长期使用表格或宽松卡片，请在设置中修改默认项。

为什么某篇文章没有 JIF 或 PDF？

JIF 只显示本地已录入的对应年份数据，缺失时留空。PDF 需要自己下载并链接，软件不会自动取得出版社全文。

数据或原始 PDF 会因升级被删除吗？

升级保持数据兼容，但建议事先完整备份。取消最后一处收藏会删除软件 paper 中的 PDF 副本，原始下载文件仍保留。移动数据目录会在校验后移走并删除旧数据。

如何查看最新版本和报告问题？

从下载页进入对应平台的 GitHub 仓库，核对 latest 发布与使用说明。反馈时可提供系统、软件版本、操作步骤和错误信息，避免附带私人文献或凭据。

为什么复制引用后仍缺少 Volume 或 Pages？

在线优先发表或预印本可能尚未分配卷页，元数据也可能延迟。字段缺失时每次点击都会尝试联网补齐，完整后使用缓存；不会为了填满格式而虚构卷页。

批量收藏 PDF 为什么有些文件失败？

先查看失败报告。常见原因包括 PubMed 未收录、所选期刊目录不包含该刊、首页缺少可提取的大标题、扫描件或网络失败。可复制或导出未成功文件名，报告需手动关闭。

为什么 Mac Word 中没有 Biomed Reader 工具栏？

Mac 2.1 采用“收藏文章 → 导出 Word / EndNote…”的文档互通方式。Windows 的 COM 插件不能直接安装到 Mac；使用 Mac Word 的 EndNote CWYW 接管导出的引文文档。
