A QUIETER READING WORKFLOW

检索之后，才是阅读的开始。

从一次关键词搜索，到一个课题的长期跟踪。减少来回切换，把检索结果慢慢变成自己的文献库。

01

课题各有一张关键词卡片

保存关键词与筛选条件，支持多个研究主题。首次建立缓存，后续按来源的成功刷新日期增量检索，并与已有文章合并去重。

02

离线，也能继续阅读

已缓存的标题、摘要和收藏可离线查看。表格快速扫读，卡片直接预览摘要，大量结果通过按需加载与分页浏览。

03

收藏、笔记与 PDF 放在一起

文章按课题归组，也可建立自己的分组。支持跨分组搜索收藏、批量取消收藏，以及批量导入 PDF 并自动匹配关联原文；收藏和期刊目录都能打包分享。

04

按自己的期刊范围筛选

使用内置或自定义期刊目录，按名称、ISSN 与 JIF 范围挑选。可选择对应年度的已录入 JIF，多目录取并集。
