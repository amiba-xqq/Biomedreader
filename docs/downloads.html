WINDOWS

安装程序，或完整目录版。

  1. 下载 EXE，按提示完成安装，然后打开刊禾。
  2. 如果使用目录版，请完整解压 ZIP，运行 BiomedReader.exe，保留 _internal 等配套文件。
  3. 升级前先在设置中备份本地数据，再退出旧软件和 Word。目录版需要 Word 插件时，完整解压到固定位置后运行 RegisterWordAddin.cmd，再重新打开 Word。
安装程序尚未数字签名，Windows 可能显示发布者提示。请核对下载仓库与文件校验值。
Windows 发布记录与校验清单 ↗

MACOS

按芯片选择对应 DMG。

  1. 在苹果菜单的“关于本机”中查看芯片。M 系列选择 Apple Silicon，Intel 处理器选择 Intel 版。
  2. 打开 DMG，将 Biomed Reader.app 拖到“应用程序”，再从应用程序文件夹启动。
  3. 若系统提示开发者无法验证，请查看仓库的系统安全设置说明。Mac 2.1 使用 Word 文档导出与 EndNote CWYW 接管；步骤见Mac 引用教程。
macOS 包使用 ad-hoc 签名，尚未经过 Apple Developer ID 公证。请从本页或对应仓库下载。
